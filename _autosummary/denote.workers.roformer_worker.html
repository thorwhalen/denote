denote.workers.roformer_worker

denote.workers.roformer_worker¶

RoFormer worker: audio-separator’s RoFormer checkpoints, run in the roformer environment.

Loaded standalone by ps.isolated.Worker (it imports nothing from denote). The mix arrives as a (channels, frames) float32 .npy file at 44.1 kHz; it is written, next to it, as a 32-bit float WAV (audio-separator reads files), separated, and each stem read back and written as <stem>.npy (lower-case stem name) in the request’s folder. Output WAVs are float too (audio-separator keeps the input’s subtype), so no level is lost to 16-bit quantization; audio-separator scales a stem down only if its peak exceeds normalization_threshold (1.0 here, its maximum).

Stems come back target first (the checkpoint’s primary stem, e.g. vocals), then the rest in the order audio-separator wrote them (it writes the secondary stem first). audio-separator writes its outputs into one folder fixed when it is built: a temporary folder of this worker, emptied after each request and removed at exit.
