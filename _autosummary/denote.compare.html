denote.compare

denote.compare¶

Compare a version of a piece with a reference: harmony and sound, on the same moments (denote#3).

align_audio() measures how closely a version follows the reference’s harmony and melody (chroma DTW), and is blind to timbre on purpose. compare_audio() adds the other half, how close the sound is, and keeps both on one footing: the two recordings are aligned once, and every metric reads the same warping path, so each compares the same musical moments.

Metrics are a registry (METRICS, a name -> metric mapping you can extend or replace through metrics=): a metric is a callable taking an AlignedPair and returning a distance (lower is closer). An embedding metric (CLAP, MERT, a Fréchet-style distance) is one more entry, with no change to callers.

Built in:

  • "chroma": the alignment’s own cost, mean cosine distance between chroma frames along the path (0 identical pitch content, 1 unrelated). Measured on an orchestral minute, an unrelated piece in the same key and style scored about 0.16-0.21 against the reference, so it discriminates mainly below about 0.15.

  • "timbre": MFCCs c1..c19 (c0, loudness, left out) of both recordings, each coefficient z-scored with statistics pooled over both (so a global difference in spectral shape is kept, not normalised away), then the root-mean-square difference per coefficient, averaged along the path. 0 is the same sound; two unrelated timbres are typically around 1. The starter it replaces (z-scored per recording) separated a General MIDI render (0.46-0.79) from a light audio-to-audio pass of the original (0.41); it is a coarse spectral-envelope measure, not a perceptual one.
