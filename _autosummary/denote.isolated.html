denote.isolated

denote.isolated¶

Backends that run in their own Python environment, through ps.isolated.

Some models cannot share an environment with denote (or with each other): demucs-mlx pins its own MLX, audio-separator needs a recent torch. Their backends declare an isolated_env in BACKEND_CONFIG (top-level requirements, a lock file resolved from them, and the Python version) and keep the model code in a worker file (denote/workers/<backend>_worker.py): a plain module, importing nothing from denote, that ps.isolated.Worker runs with the environment’s interpreter. Requests and replies are JSON lines; audio crosses as .npy files in a temporary folder.

Where things live (DENOTE_DATA_DIR replaces the root):

~/.local/share/denote/
    envs/<backend>/      the backend's environment (built by uv)
    models/<backend>/    weights a backend keeps itself (when its library has no
                         cache of its own outside a temporary folder)

Nothing is built implicitly: a missing environment raises EnvNotBuilt, whose message is the command that builds it (python -m denote.isolated build <backend>), unless the caller passes build_env=True.

An environment is installed from its backend’s lock (env.lock next to its config: every package pinned, with platform markers, as uv pip compile --universal resolves the top-level requirements), so it is the same wherever and whenever it is built, and changing the lock changes the spec’s digest (the next build starts afresh). python -m denote.isolated lock <backend> re-resolves it.

A worker keeps its model in memory (several GB for these models) until it is closed (denote.services[<backend>].close()) or the host process exits.

>>> spec = env_spec({"name": "toy", "isolated_env": {"requirements": ["numpy==2.1.0"]}})
>>> spec.name, spec.requirements
('toy', ('numpy==2.1.0',))
>>> build_command("toy")
'python -m denote.isolated build toy'

class denote.isolated.IsolatedSeparator(config)[source]¶

Bases: object

Host side of a separation backend whose model runs in a worker (see module doc).

Subclasses set MODEL_SR and may override worker_init() (the worker’s load arguments) and request() (one separate call’s). The worker starts on the first call (the model loads once) and is reused; close() stops it. Config needs param_map with model, sources and build_env.

CHANNELS = 2¶

Channels the model takes (mono is duplicated, extra channels dropped).

MODEL_SR = 44100¶

The rate the model runs at; the mix is resampled to it on the host.

Separate a mix into stems in the backend’s own environment.

Parameters:

  • audio – File path or numpy array (mono, (frames, channels) or (channels, frames)); mono is duplicated to stereo.
