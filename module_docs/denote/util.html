denote.util

Audio loading and utility functions for denote.

denote.util.ensure_file_path(audio: str | Path | ndarray, *, sr: int | None = None) → str[source]

Ensure audio is available as a file path.

If audio is already a path, return it as a string. If it’s an array, write to a temporary WAV file and return the path.

denote.util.load_audio(audio: str | Path | ndarray, *, sr: int | None = None, mono: bool = True, target_sr: int | None = None) → Tuple[ndarray, int][source]

Load audio from a file path or validate an existing array.

Parameters:

  • audio – File path (str/Path) or numpy array of audio samples.

  • sr – Sample rate. Required when audio is an array. Ignored for file paths (detected automatically).

  • mono – If True, convert to mono.

  • target_sr – If set, resample to this rate.

Returns:

Tuple of (audio_array, sample_rate).

Raises:

  • ValueError – If audio is an array and sr is not provided.

  • FileNotFoundError – If audio is a path that doesn’t exist.
